# QR Code Generator

A simple web application that allows users to generate a QR code from a valid URL or text input and download it as an image.

This project was created as a beginner practice project for learning basic web development concepts using **HTML, CSS, and JavaScript**.

## Features

- Generate QR codes from:
  - URLs
  - Plain text
- Instant QR code preview
- Download the generated QR code as an image
- Simple and responsive interface

---

## How It Works

1. The user enters a valid URL or text in the input field.
2. By clicking the **Generate QR** button, the application creates a QR code.
3. Once the QR code is generated, a **download button/link** appears.
4. The user can download the QR code image and use it anywhere.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

The application is built without frameworks to practice core web development concepts.
